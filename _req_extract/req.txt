项目需求v.1.1
TO B
店铺Dashboard
描述
商家管理后台首页（数据概览看板），面向店铺运营 / 商家用户，集中展示订单状态汇总、实时交易趋势、核心经营指标、系统消息通知，作为商家登录后的首页工作台，快速掌握店铺整体经营情况。
目标用户
商家、店铺运营人员
权限
登录商家账号才可访问；只查看当前登录店铺数据，不可查看其他店铺
需求
描述
非功能需求
顶部订单状态卡片模块（6 个统计卡片）
每个卡片：数字 + 业务名称 + 图标
待付款订单：统计当前状态为待付款订单总数；数值：0
待发货：已付款、尚未发货订单总数；数值：12
待收货：已发货、买家未确认收货订单总数；数值：2
已完成：交易完结（买家确认收货）订单总数；数值：24
退款 / 售后：正在进行退款、售后申请单据总数；数值：1
库存预警：库存低于阈值的商品数量；数值：3
实时数据趋势图表
折线图 X 轴：一天 24 小时（0:00 ~23:00）
两条曲线：
蓝色：今日支付金额
绿色：昨日支付金额
Y 轴：交易金额，自动适配数值范围
作用：对比今日和昨天全天的交易金额走势，看高峰时段
统计响应 < 1s
数据统计指标卡片（4 项核心经营数据）
每项包含：指标名称、当前数值、同比昨日变化率
支付客户数：今日完成付款独立客户数量；同比昨日 +100.00%
支付订单数：今日成功支付订单总量；同比昨日 +100.00%
退款金额 (元)：今日退款总金额；同比昨日 +0.00%
客单价 (元)：今日总支付金额 ÷ 支付订单数；同比昨日 +100.00%
同比计算公式：(今日值 - 昨日值) ÷ 昨日值 *100%；昨日无数据时显示 100%
统计响应 < 1s
消息通知模块
消息为列表滚动展示，每条消息为通知文本
消息类型：
订单支付成功通知：用户 xxx 已支付成功，订单号 xxx，请及时处理
退款申请通知：有买家发起退款，订单编号 xxx，请在 7 天内处理
确认收货通知：订单 xxx 用户 xxx 已经确认收货
每条消息携带订单编号；点击单条消息，跳转对应订单详情页
消息按时间倒序展示，最新消息在最上方
店铺商品管理
描述
维护商品信息、库存、上下架的核心工作台。支持多维度商品筛选、商品批量操作、单商品编辑管理，用于店铺全部商品的统一维护。
目标用户
商家、店铺运营人员
权限
登录商家账号才可访问；只查看当前登录店铺数据，不可查看其他店铺
需求
描述
非功能需求
顶部筛选
筛选项        控件类型        说明
商品名称        文本输入框        模糊搜索商品名称关键词
商品类型        下拉选择框        普通商品、秒杀商品等
商品类别        下拉选择框        实物商品 / 虚拟 / 卡券等类别
状态        下拉选择框        上架、下架
配送方式        下拉选择框        同城配送、用户自提、快递配送等，支持多选组合
商品分类        下拉选择框        商品所属类目分类
功能按钮
搜索：根据筛选条件查询商品列表
重置：清空全部筛选条件，恢复列表初始状态
全选复选框：勾选当前页所有商品条目，用于批量操作
导出：导出当前筛选后的商品列表数据为 Excel 文件
导入商品：弹窗上传 Excel 模板，批量新增 / 更新商品
批量设置（下拉按钮）：展开批量操作菜单，支持批量修改商品状态、配送方式、分类、排序、库存等
商品列表
商品信息：商品缩略图 + 商品名称
市场价 (元)：划线原价
销售价 (元)：前台售卖价格
商品销量：真实成交销量
注水销量：虚拟销量（商家可配置）
仓库库存：中心仓库库存数量
门店库存：门店可售库存数量
商品类型：普通商品 / 秒杀商品
商品类别：实物商品等
状态：上架 / 下架
配送方式：展示支持的配送类型（同城配送 / 用户自提 / 快递配送）
排序：数字，数字越大前台展示越靠前
操作列（单品操作）
编辑：跳转商品编辑页面，修改商品基础信息、价格、库存、图文、配送等
下架：上架商品显示【下架】按钮，点击变更商品状态为下架；下架商品对应显示【上架】
删除：删除商品，弹出二次确认弹窗；已产生订单的商品禁止删除
订单管理 - 订单查询页面
描述
订单查询列表页，是商家核心订单操作工作台。支持多维度筛选订单、查看订单明细、批量与单条订单操作，满足商家查询、管理、处理店铺全部订单的业务需求
目标用户
商家、店铺运营人员
权限
登录商家账号才可访问；只查看当前登录店铺数据，不可查看其他店铺
需求
描述
非功能需求
顶部筛选
筛选项        控件类型        说明
订单编号        输入框        支持精确输入订单号检索
订单类型        下拉选择框        可选订单业务类型
订单类别        下拉选择框        区分普通订单、电子卡券订单等类别
订单状态        下拉选择框        待付款 / 待发货 / 待收货 / 交易成功 / 交易失败 / 待成团
收件人姓名        输入框        按收件人姓名模糊搜索
联系电话        输入框        收件人手机号模糊检索
支付方式        下拉选择框        用户余额支付、微信、支付宝等
售后状态        下拉选择框        暂无售后、退款申请中、退款完成等
物流类型        下拉选择框        普通快递、同城配送等
门店名称        下拉 / 输入框        多门店模式，筛选对应门店订单
下单时间        日期区间选择器        开始日期～结束日期；内置快捷选项：今日、昨日、近 7 天、近 30 天
功能按钮
查询：根据上面所有筛选条件，查询并刷新订单列表
导出：将当前筛选后的订单列表数据导出 Excel 文件
重置：清空所有筛选条件，恢复默认，刷新列表
批量发货：批量勾选订单，执行批量发货操作
订单状态快捷标签栏
快捷筛选标签：全部、待付款、待发货、待收货、交易成功、交易失败、待成团
点击标签，自动填充订单状态筛选条件，直接刷新列表，快速过滤订单
每行订单组展示内容
订单头部信息：订单编号 + 下单时间；多门店订单额外展示门店名称
商品信息：商品图片、商品名称；标签标记特殊类型：待发货/待收货/退款申请中/电子卡券订单/同城配送；赠品标记
成交单价 / 数量：单品单价，购买数量
实付金额：订单实付总金额（红色字体突出），标注共 N 件
支付方式：用户余额支付 / 微信支付等
买家 / 收货人：买家账号、收件人脱敏手机号
订单状态：待付款 / 待发货 / 待收货 / 交易成功 / 交易失败 / 待成团
售后状态：暂无售后、退款申请中等
操作列（单订单操作）
查看详情：跳转订单详情页面
联系买家：唤起和买家的聊天窗口
发货：待发货订单才展示该按钮，弹出发货弹窗，填写物流单号
退款信息：存在售后退款时展示，跳转退款售后处理页面

订单管理模块
描述
实现用户订单统一管理，支持订单多状态分类查看、订单检索、订单详情查看、订单操作（复购、收藏），清晰展示商品、金额、订单状态信息。
目标用户
c端用户
权限
登录账号才可访问；只查看当前用户数据
需求
描述
非功能需求
订单状态标签（顶部 Tab）
全部订单：展示用户所有订单，包含已取消、待发货、已完成等
待付款：显示待付款订单，括号内为订单数量，当前示例：0
待发货：显示已支付但商家未发货订单，括号内为订单数量，当前示例：9
待收货：已发货，等待用户确认收货订单，当前示例：0
已完成交易完成订单，当前示例：10
筛选与查询区域
订单编号查询
输入框：提示文字「请输入订单编号查询」
查询按钮：红色【查询订单】，点击按订单号精确检索。
订单列表 - 订单卡片（一条订单为一个卡片）
订单头部信息
订单编号：
店铺名称：店铺图标、电话图标
右侧删除图标：可删除订单记录
商品行（一个订单可包含多个商品）
每个商品条目字段：
商品图片
商品名称
数量：x1 / x8
单价：¥xxx.00
总额：订单合计金额（同一订单多个商品合并总额）
状态：订单整体状态，如「已取消」「待发货」，待发货附带支付方式：余额支付
操作按钮（按订单状态动态展示）
各操作功能说明
订单详情：弹窗 / 新页面打开，查看订单完整明细、物流、支付记录。
